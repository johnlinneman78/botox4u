## Quick Updates

### 💻 Development
```bash
npm run notion:update dev "Task name" "Feature" "High" "In Progress" 6
```

### 📢 Marketing
```bash
npm run notion:update marketing "Campaign name" "social" "Blog Post" "Planned" "High"
```

### 💰 Revenue
```bash
npm run notion:update revenue "Description" "Subscriptions" 99 "Paid" true
```

### 👤 Provider
```bash
npm run notion:update provider "Name" "City" "State" "Premium ($99/mo)"
```

### 🔍 SEO
```bash
npm run notion:update seo "keyword" 10 500
```

## Common Examples

```bash
# Log today's work
npm run notion:update dev "Built city page template" "Feature" "High" "Done" 8

# New subscriber!
npm run notion:update revenue "New Premium Sub - LA Spa" "Subscriptions" 99 "Paid" true

# Content published
npm run notion:update marketing "Botox Guide Miami" "content" "City Page" "Published" "High"

# Track ranking improvement
npm run notion:update seo "botox miami" 8 350
```
